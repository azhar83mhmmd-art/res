Kebijakan Privasi

Halaman ini menjelaskan secara sederhana bagaimana Kairoo API menangani data. Ini bukan dokumen hukum formal.

Data yang Dikumpulkan

Kairoo mencatat data teknis dari request API yang masuk: waktu, metode HTTP, path endpoint, kode status, dan waktu respons. IP pengguna diproses menjadi hash satu arah (bukan disimpan mentah) untuk keperluan statistik pengguna unik dan rate limiting.

Request Logs

Log request terbaru ditampilkan di halaman Live Request Logs untuk transparansi performa API. Log ini tidak menampilkan API key, header Authorization, cookie, password, atau body request pengguna.

Penggunaan API

Data statistik agregat (jumlah request, latency, error rate) digunakan untuk memantau kesehatan sistem dan meningkatkan performa layanan. Kairoo tidak menjual atau membagikan data request kepada pihak ketiga untuk tujuan iklan.

Keamanan

Kredensial layanan (kunci API pihak ketiga, service role key database, token Redis) disimpan sebagai environment variable di server dan tidak pernah dikirim ke frontend atau ditampilkan di respons API.

Penyimpanan Data

Log request individual disimpan sementara dan dibersihkan secara berkala. Data agregat harian (jumlah request, rata-rata response time) disimpan lebih lama untuk keperluan statistik historis.

Formulir Feedback

Jika Anda mengisi nama atau email pada formulir Feedback, data tersebut bersifat opsional dan hanya digunakan untuk menindaklanjuti laporan Anda, bukan untuk keperluan pemasaran.

Hak Pengguna

Karena Kairoo tidak mewajibkan akun/login untuk mengakses sebagian besar endpoint publik, sebagian besar interaksi bersifat anonim dari sisi identitas pribadi. Untuk pertanyaan terkait data yang Anda kirimkan lewat formulir Feedback, silakan hubungi kami melalui halaman Feedback.
